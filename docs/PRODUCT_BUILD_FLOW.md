# 产品制作流程逻辑

本流程只描述产品制作逻辑，不包含申报、宣传、调研组织和经费安排。

## 1. 指令采集

采集山区农业场景中的自然语言指令，重点覆盖巡田、定位、喷洒、查看作物、绕障、返航等常见任务。

输出物：

- 原始语音文件
- 原始文本指令
- 方言词汇和农事术语表

存放位置：

```text
data/raw/audio/
data/raw/text/
```

## 2. 数据清洗与结构化标注

对采集到的语音和文本进行去噪、筛选、分类和标注，将自然语言整理为可训练、可解析的数据。

标注字段建议包括：

- `intent`：任务意图，如起飞、降落、巡田、喷洒、返航
- `target`：目标区域，如玉米地、果园、水渠旁
- `action`：动作类型，如飞到、巡视、悬停、喷洒
- `height`：飞行高度
- `speed`：飞行速度
- `route_hint`：路线提示
- `safety_limit`：安全限制

输出物：

```text
data/processed/instructions/
```

## 3. 语音识别模块制作

将农户语音转换为文本，优先保证弱网或离线环境下的可用性。

模块位置：

```text
src/swing_control/asr/
```

输入：

- 语音文件
- 麦克风实时音频

输出：

- 文本指令

## 4. 指令解析模块制作

把文本指令转换为结构化任务。

模块位置：

```text
src/swing_control/nlp/
```

示例：

```text
输入：飞到那片玉米地上方巡视
输出：intent=inspect, target=玉米地, action=巡航巡视
```

## 5. 山区空间地图制作

构建目标测试区域的地图数据，标注农田边界、果园、植被、建筑物、电线、山坡、禁飞区和安全降落点。

模块位置：

```text
src/swing_control/mapping/
```

数据位置：

```text
data/maps/
```

输出：

- 地块坐标
- 障碍物坐标
- 禁飞区边界
- 安全飞行区域

## 6. 语言目标与地理坐标匹配

将“那片果园”“山坡上的玉米地”“靠近水渠的区域”等模糊表达映射为具体坐标或区域。

输入：

- 结构化任务
- 地图语义标注

输出：

- 目标坐标
- 目标区域边界
- 可飞行区域

## 7. 路径规划模块制作

根据目标位置、地形、障碍物和任务类型生成飞行路径。

模块位置：

```text
src/swing_control/planning/
```

路径应包含：

- 起飞点
- 目标点
- 中间航点
- 避障航点
- 返航点
- 降落点

## 8. 安全控制模块制作

在飞行前和飞行中检查任务是否安全。

模块位置：

```text
src/swing_control/safety/
```

安全检查包括：

- 异常指令拦截
- 地理围栏检查
- 最大高度限制
- 最小安全高度限制
- 障碍物距离检查
- 低电量返航
- 失联悬停或返航
- 人工确认起飞

## 9. 飞控执行模块制作

将路径规划结果转换为无人机飞控指令，实现起飞、移动、转向、悬停、巡航、模式切换、降落和断开连接。

模块位置：

```text
src/swing_control/flight/
```

当前可运行脚本：

```text
model/run_swing_direct_flight.sh
model/demoSwingDirectFlight.py
```

## 10. 闭环系统集成

把各模块串联成完整流程：

```text
语音输入
  -> 语音识别
  -> 指令解析
  -> 地图匹配
  -> 路径规划
  -> 安全校验
  -> 飞控执行
  -> 日志记录
  -> 反馈优化
```

模块位置：

```text
src/swing_control/app/
```

## 11. 实验室测试

先不进入真实山区场景，进行仿真和基础动作测试。

测试内容：

- 指令识别准确率
- 指令解析正确率
- 路径规划合理性
- 安全拦截是否有效
- 无人机连接是否稳定
- 起飞、降落、悬停、移动是否正常

## 12. 实地测试与迭代

在真实山区农业场景中验证产品原型。

记录内容：

- 识别错误
- 路径偏差
- 响应延迟
- 飞行误差
- 蓝牙或网络异常
- 用户操作反馈

日志位置：

```text
data/logs/
```

## 13. 原型交付

最终形成可演示的产品原型，至少包含：

- 可运行的无人机控制脚本
- 语音或文本指令输入入口
- 指令解析逻辑
- 路径规划逻辑
- 安全控制逻辑
- 测试日志
- 操作说明文档
